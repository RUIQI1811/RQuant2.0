## ChinaAShareEquityCharacteristics (characteristic definitions only)

`src/rquant/factors/libraries/china_chars.py` implements a daily, point-in-time
version of the characteristic list published by
https://github.com/Quantactix/ChinaAShareEquityCharacteristics (`char_list.csv`
and the accompanying academic definitions, mainly Hou, Xue and Zhang's anomaly
catalog). No source code from that GPL-3.0 project was copied or translated:
RQuant re-implements each characteristic from its published definition with
Tushare inputs, its own windows and its own point-in-time rules, and omits the
characteristics that need data RQuant does not collect.

## TA-Lib 0.8.2

`src/rquant/factors/libraries/talib_indicators.py` compiles selected TA-Lib C
functions into its KunQuant graph. `extensions/ta_lib/ta_lib.hpp` vendors the
double-precision batch functions, lookbacks and required helpers from TA-Lib
0.8.1 (https://github.com/TA-Lib/ta-lib), generated by `scripts/vendor_ta_lib.py`.
The generator makes functions static inline inside `rq_ta_lib` and adapts
allocation for C++; `scripts/ta_lib_compat.hpp` supplies the required macros
and default settings. The generated header retains the upstream copyright
notice and BSD 3-Clause license text. RQuant selects parameters, processes
each stock's consecutive quotes and rescales price-unit outputs.

The independent parity reference uses the `TA-Lib==0.8.2` Python package
(https://github.com/TA-Lib/ta-lib-python).

The Python wrapper is licensed under the BSD 2-Clause License and the C library
under the BSD 3-Clause License. See `licenses/TA-Lib-0.8.2-LICENSE.txt` for the
license text shipped with the installed package.
