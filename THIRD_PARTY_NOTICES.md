# Third-party notices

## Jensen-Kelly-Pedersen extended characteristic definitions

`src/rquant/factors/libraries/jkp406.py` and `jkp406_catalog.py` independently
implement the supported A-share adaptation of the extended Global Factor Data
definitions from Jensen, Kelly and Pedersen, "Is There a Replication Crisis in
Finance?", The Journal of Finance 78(5), 2465-2518 (2023).

Sources: https://jkpfactors.com/ and
https://jkpfactors-data.s3.amazonaws.com/documents/Documentation.pdf;
the explicit source inventory is pinned to `bkelly-lab/ReplicationCrisis`
commit `67174c7f170bf8b952b3c86876f187fd9970b5ba` (GlobalFactors accounting,
market and combined characteristic exports), cross-checked against
`bkelly-lab/jkp-data` commit `c1762b9272f2743d8191561aa371d1101d37536c`.

No upstream executable code or datasets are copied, translated or bundled.
Characteristic identifiers and published mathematical definitions are used as
metadata and specifications. The current Python project's code is MIT licensed;
the authors' distributed data are CC BY-NC 4.0. This implementation uses only
Tushare inputs and does not distribute the authors' data.

Modifications include 21-trading-day months, quarterly TTM statement flows,
actual first-announcement alignment, research-universe composites and explicit
data-availability omissions. The 144 inherited `jkp153` definitions are retained.
The advertised 406 count is reconciled as 404 explicitly named characteristics
plus a two-name documentation/source discrepancy; 364 named characteristics are
implemented and 40 are excluded with reasons. See the module and README for
the exact adaptation and omissions.

## ChinaAShareEquityCharacteristics (characteristic definitions only)

`src/rquant/factors/libraries/china_chars.py` implements a daily, point-in-time
version of the characteristic list published by
https://github.com/Quantactix/ChinaAShareEquityCharacteristics (`char_list.csv`
and the accompanying academic definitions, mainly Hou, Xue and Zhang's anomaly
catalog). No source code from that GPL-3.0 project was copied or translated:
RQuant re-implements each characteristic from its published definition with
Tushare inputs, its own windows and its own point-in-time rules, and omits the
characteristics that need data RQuant does not collect.

## TA-Lib 0.8.2

`src/rquant/factors/libraries/talib_indicators.py` compiles selected TA-Lib C
functions into its KunQuant graph. `extensions/ta_lib/ta_lib.hpp` vendors the
double-precision batch functions, lookbacks and required helpers from TA-Lib
0.8.1 (https://github.com/TA-Lib/ta-lib), generated by `scripts/vendor_ta_lib.py`.
The generator makes functions static inline inside `rq_ta_lib` and adapts
allocation for C++; `scripts/ta_lib_compat.hpp` supplies the required macros
and default settings. The generated header retains the upstream copyright
notice and BSD 3-Clause license text. RQuant selects parameters, processes
each stock's consecutive quotes and rescales price-unit outputs.

The independent parity reference uses the `TA-Lib==0.8.2` Python package
(https://github.com/TA-Lib/ta-lib-python).

The Python wrapper is licensed under the BSD 2-Clause License and the C library
under the BSD 3-Clause License. See `licenses/TA-Lib-0.8.2-LICENSE.txt` for the
license text shipped with the installed package.
