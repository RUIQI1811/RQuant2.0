# J Law 策略的量化近似（规则清单）

J Law（2024、2025 年两届美国投资冠军赛 USIC 百万美元组冠军，年回报 353.9% / 252.3%）没有公开一套完全机械的交易系统，
公开的只有原则。这里把每条原则改写成一条可回测的规则，代码在 `src/rquant/workflow/jlaw.py`（`RULES` 和 `JLawParams`），
回测脚本是 `scripts/analysis/jlaw_backtest.py`。

「出处」一栏写明哪些是他本人说过的（数字也是他的），哪些是转述，哪些只是这里为了能回测而定的近似。

## A 股撮合口径

- 只做多，现金账户，不加杠杆（他比赛时用了杠杆）。
- 日线撮合：止损用当天最低价判断，触发后按止损价成交，低开在止损下方则按开盘价成交；一字跌停卖不出，次日开盘再卖。
  日线看不出盘中先碰止损还是先碰别的价位，这是近似。
- T+1：当天买的股票当天不能卖。买入按 100 股取整。佣金万三、最低 5 元，印花税 2023-08-28 前千一、之后千分之 0.5。
- 价格用复权价，持仓按复权单位记，分红送股视为再投资。没计冲击成本。
