# China 469: Cop, Cla and Claq source-timing design

The user requested accurate missing definitions, excluding formulas merely related to existing implementations. The official appendix A.4.18–20 defines the numerator as operating profit minus net income plus operating cash flow. Cop divides annual values by contemporaneous total assets; Cla divides by prior-year total assets; Claq divides single-quarter flows by prior-quarter assets. JKP TTM reconstruction is not equivalent. CSMAR-vs-Tushare numerical equivalence is not established, so name the result a Tushare adaptation, not exact CSMAR reproduction.

Preserve all existing factor contracts and shared uncommitted changes. Build an independent three-output KunQuant factor set with stable prefix `cnax_`, using current Tushare statement fields. Financial formulas run in the KunQuant statement graph. Two library families in one registered factor set can own separate quarterly and annual `QuarterGrid` publication timelines. The actual design of eligibility dates must preserve all older eligible records, apply month-end/year-end formation to the historical calendar, require first-announcement availability, and never backfill an event after its cutoff. The later periodic value is fixed until the next formation; a missing eligible report stays missing. Calendar-day month arithmetic is not a 21-day approximation. Actual first-announcement times are unavailable, so a report dated the formation trading day is not eligible for an opening-time monthly formation. Annual month-end signal is formed after that close and filled next trading day; announcements on the formation day are eligible at that close under the existing daily announcement contract.

Monthly quarter eligibility is `quarter end + 4 calendar months <= formation date`, with the latest quarter that is both eligible and announced before the formation trading day. For annual formation use last trading day of June, selecting only the previous calendar year's Q4 report available by that date; do not substitute older fiscal years. Avoid incomplete initial calendar periods, disclose any conservative handling, and test weekends, holidays, late and out-of-order reports. Quarterly flows are differenced from cumulative figures within the same fiscal year; stock-day output is absent on non-trading days. Ratios reject a zero denominator; do not silently assume CSMAR/Tushare values match.

Output requirements: source attribution and version, explicit field mapping and omission caveats, prefix stability, fingerprinting of all shared code, numerical test against independent calculations including masks, truncation tests, full Python 3.11 Ruff and pytest, and independent quantitative review. Do not run multiple large tests/builds at once; do not update existing factor stores or data in this implementation task.
