# Shanghai main-board backtest defaults

**Goal:** Apply the user's confirmed Shanghai main-board universe (historical ST and first-60-trading-day exclusions), with top 50 / drop 50 / every 5 trading days for 5d labels and top 50 / drop at most 5 / daily for 1d labels.

**Design:** Change the shipped universe to sh_main. Report resolves a horizon profile from walk_forward.json, overlays that profile on common backtest settings, then applies explicit CLI overrides. Existing configurations without profiles keep their prior behavior. The training run remains authoritative for universe. Existing reports are not regenerated by changing defaults.
